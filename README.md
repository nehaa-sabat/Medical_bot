# 🏥 AI-Powered Healthcare Assistant with NLP & Knowledge Retrieval

An AI-driven healthcare chatbot that answers medical questions using **Natural Language Processing (NLP)** and **knowledge retrieval** from a verified medical knowledge base.  
Built using **LangChain**, **FAISS vector store**, and **Groq API**, and deployed as an interactive **Streamlit** web app.

---

## 🚀 Features

- 🧠 **Context-Aware Q&A** using LangChain
- 📚 Verified medical knowledge base from curated PDF documents
- 🗂 **Vector Database (FAISS)** for efficient memory & retrieval
- 🔍 Sentence embeddings with `sentence-transformers/all-MiniLM-L6-v2`
- 💬 LLM-powered responses using `google/flan-t5-small` via **Groq API**
- 🌐 User-friendly **Streamlit** web interface

---
